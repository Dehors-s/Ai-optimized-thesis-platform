# 25 精美图表的画像：从 196 张已标图里分门别类看出来的

> "精美"不该由我拍脑袋定义。这一版从语料里每类抽 6 张做拼版，
> 逐类看，再用像素指标佐证，最后落成模板规则。
>
> 样本拼版：`corpus/figures/corpus/category_sheets/`（map / architecture /
> distribution / qualitative / scatter / heatmap / profile / timeseries）。

---

## 0 先给结论：精美 = 六个可检查的量

1. **墨量低**：白底、无外框、无阴影、无 3D；非数据元素尽量少。
2. **层级清**：字号三档（面板字母 > 轴标题 > 刻度），行/列标签只出现一次。
3. **颜色有角色**：一个主色 + 灰 + 强调色；连续色标用于场，定性色板用于类别。
4. **对齐**：面板等宽等高、共享轴、同一裁切；白缝一致。
5. **直接标注**：能标在端点/柱顶/块上的，不做图例；图例 ≤3 条。
6. **留白**：边距大于边框，标签不压数据；该空的空，该密的密。

这六条比"高级感"可操作，也能被 lint 检查。

---

## 1 方法

- 从 196 张人工标注里，每类抽 6 张（不足全取），拼成类别页；
- 逐类看布局、字号、配色、坐标轴、标注、图例；
- 用像素指标佐证（400px 缩略图）：
  - 白底占比、颜色丰富度、量化颜色数、边缘密度、长宽比。

| 类别 | n | 白底 | 颜色丰富度 | 颜色数 | 边缘密度 | 长宽比 |
|---|---|---|---|---|---|---|
| 架构 | 57 | 51% | 28.6 | 140 | 35.8 | **2.0** |
| 地图 | 49 | 46% | 56.2 | 170 | 35.6 | 1.37 |
| 分布 | 28 | **77%** | 31.4 | 122 | 29.6 | 1.55 |
| 定性 | 25 | **20%** | 45.1 | 159 | 35.5 | 1.44 |
| 散点 | 13 | **84%** | 19.7 | 91 | 27.6 | 1.61 |
| 热力图 | 5 | 48% | 69.4 | **41** | 28.0 | 1.26 |
| 剖面 | 4 | 45% | 140 | 216 | 44.4 | 1.37 |
| 时序 | 3 | 82% | 34.5 | 178 | 39.8 | 1.65 |

读法：

- **散点/分布白底 77%—84%**：数据图要"空"，墨留给数据和标注；
- **定性白底 20%**：图像网格天然满，靠白缝和裁切而不是留白；
- **热力图颜色数只有 41**：少色、连续、靠标注读数；
- **剖面颜色数 216、颜色丰富度 140**：场图颜色多，但也是最容易"花"的一类，要克制；
- **架构图长宽比 2.0**：横向叙事，天然比数据图宽。

## 2 分门别类的观察

### 2.1 地图（map）

样本：GMD/ESSD 的全球/区域分布图、差值图。

共性：

- **底图灰、数据彩**：陆地浅灰、海洋白，只有数据层着色；
- **一个色标管一类变量**：同变量多面板共用一个色标，色标贴边、单位写在标签里；
- **差值图用发散色标**（RdBu），正负对称，零居中；
- **面板字母 A/B/C 或 (a)(b)**，标题短；
- 区域图带比例尺/指北针，全球图用经纬度框；
- 色标刻度稀疏（3—5 个），不标每个刻度。

反例：多面板各画一个色标、色标范围不一致、底图也着色。

### 2.2 架构（architecture）

样本：HyperFree、LOGCAN++、DCT-Mamba、RSDG、DOFA 等。

共性：

- **角色色**：训练/可学习一色、冻结一色、本文模块一色、数据一色；
- **框等宽、箭头正交**，残差走外侧；
- **虚线容器**分组，容器角标 (a)(b)；
- **图例只解释线型/算子**（冻结、可训练、⊕），不解释每个模块；
- 能嵌真实图片就嵌（遥感切片、特征图），但图片有统一裁切；
- 字号 6—8pt，靠大画幅而不是放大字号；
- 重复用 N× / ⋯，不画 N 层。

反例：每个框不同颜色、箭头斜穿、图例十几条。

### 2.3 分布（distribution）

样本：水平条形+累计曲线、双行直方图、光谱曲线、联合分布。

共性：

- **直接标注**：柱端写数值/百分比，不靠读轴；
- **双轴只用于同一变量的两种度量**（数量 vs 百分比），轴线颜色与数据对应；
- **联合分布带边际直方图**，主图与边际共享坐标；
- 少网格、无外框；
- 颜色用于编码数值（连续色标）或分组（定性色板），不用于装饰。

### 2.4 定性（qualitative）

样本：分割/分类结果网格、检索结果、误差图。

共性：

- **行=条件/样本，列=方法**，列标题一次，行标签一次；
- **同一裁切、同一缩放、同一色板**；白缝 1—3px；
- **ROI 框**（红/绿虚线）复制到每格，差异自己跳出来；
- 可加误差图（白=错、黑=对）作为第二行；
- 不放坐标轴、不放网格、不放外框。

反例：每格裁切不同、色板不一致、格内写方法名导致拥挤。

### 2.5 散点（scatter）

样本：拟合散点、联合分布、性能-相似度散点。

共性：

- **小点、半透明、无描边**；密集时用密度色或六边形；
- **拟合线细**（1—1.5pt），R²/斜率直接标在图上；
- 边际直方图淡灰；
- 图例条目少，或直接标系列名；
- 轴范围贴合数据，不强制从 0 开始（除非有基线含义）。

### 2.6 热力图（heatmap）

样本：混淆矩阵、相似度矩阵、二值掩码。

共性：

- **少色连续色标** + 格内数值（百分比/相关系数）；
- 对角线/目标区域用更深色或框强调；
- 不画网格线，靠色块分隔；
- 标签一次，旋转 45° 或水平；
- 色标垂直贴右，刻度 3—5 个。

### 2.7 剖面（profile）

样本：气象/海洋的垂直剖面、时间-高度图。

共性：

- **填色等值线 + 细等值线**，色标横放底部；
- 多面板共享坐标，面板字母 A—D；
- 风场叠加箭头（quiver），密度克制；
- 颜色多，但同一变量同一色标。

注意：这类图最容易用彩虹色（jet），可读性差；能用 viridis/cividis 就用。

### 2.8 时序（timeseries）

样本：多站点序列、小倍数。

共性：

- 共享 x 轴，只在底部标时间；
- 直接标端点的系列名，少图例；
- 小倍数 2×3 或 1×N，面板等宽；
- 线宽 1—1.5pt，颜色不超过 5 种。

## 3 跨类别的十条规则

1. 白底、无外框、无阴影、无 3D。
2. 字号三档：面板字母 8—9pt、轴标题 8pt、刻度 7pt；最小 7pt。
3. 一个主色 + 灰 + 强调色；连续色标只用于场，定性色板只用于类别。
4. 同变量多面板共用一个色标；色标贴边，单位进标签。
5. 能直接标注就不做图例；图例 ≤3 条，放图外或底部。
6. 行列标签只出现一次；面板字母小、白底、左上。
7. 面板等宽等高、共享轴、同一裁切；白缝一致。
8. 地图底图灰、数据彩；差值用发散色标、零居中。
9. 散点小、半透明、无描边；拟合线细，统计量直接标。
10. 架构图角色色 + 正交箭头 + 虚线容器；重复用 N×。

## 4 对模板库的改造

| 模板 | 按画像改什么 |
|---|---|
| `line_ci` | 端点直接标系列名；CI 带更淡；轴范围贴数据 |
| `bar_group` | 柱顶标数值；图例移到轴外；y 轴不从 0 起时要说明 |
| `scatter_fit` | 点更小、半透明；R² 标注；加边际直方图（可选） |
| `heatmap` | 格内百分比；少色；加细色标 |
| `violin` | 中位数线细；去外框；分组色不超过 4 |
| `contour` | 换 viridis；加细等值线；色标横放底部 |
| `quiver` | 箭头更细、密度可调；底图淡 |
| `cnn` | 角色色；框等宽；图例只解释线型 |
| `pipeline` | 标签短；箭头统一；容器可加虚线 |
| `qualitative` | 行标签、列标题一次；ROI 一致；误差行可选 |

---

## 5 边界

- 每类只抽了 6 张，结论是"常见做法"，不是"唯一正确"；
- 像素指标是代理，不能替代人眼；"精美"仍有判断成分；
- 语料以地学 OA + arXiv 为主，医学/人文的规范未覆盖；
- 颜色偏好因期刊而异（Nature 偏克制，IEEE 偏饱和），模板要能换主题。

## 6 模板 lint（已实现）

```bash
py tools/template_lint.py --all
py tools/template_lint.py --template bar_group
py tools/template_lint.py --all --json
```

检查项（R1—R7，来自十条规则里可机器判的部分）：

| 规则 | 查什么 | 严重度 |
|---|---|---|
| R1 | 白底占比、上/右边框、3D | warn/fail |
| R2 | 最小字号 | fail |
| R3 | 角色色种类数 | warn |
| R5 | 图例条目数 | fail |
| R7 | 长宽比 | warn |

按图类给不同阈值（不是一套阈值管所有图）：

| 图类 | 字号 | 图例 | 白底 | 长宽比 | 色数 |
|---|---|---|---|---|---|
| timeseries | ≥6 | ≤3 | 50—90% | 1.2—2.2 | — |
| distribution | ≥6 | ≤2 | 55—90% | 1.2—2.0 | 2—10 |
| scatter | ≥6 | ≤2 | 60—95% | 1.0—2.0 | 2—8 |
| heatmap | ≥4.5 | ≤1 | 5—70% | 0.8—1.6 | — |
| field | ≥5 | ≤2 | 0—95% | 1.0—2.0 | — |
| architecture | ≥5.5 | ≤2 | 35—80% | 1.0—2.6 | 3—12 |
| flow | ≥5.5 | 0 | 50—95% | 1.0—3.2 | 2—10 |
| qualitative | ≥4.8 | 0 | 0—40% | 1.1—1.8 | — |

当前 10 个模板全部 PASS。负向测试（人为给坏指标）能报出：

```
bar_group  fail 最小字号 4.0 < 6.0
bar_group  fail 图例 5 条 > 2
bar_group  fail 使用了 3D 坐标轴
heatmap    fail 最小字号 4.0 < 4.5   # 阈值更宽
cnn        fail 角色色 20 种 不在 3—12
```

**注意**：阈值是从 196 张标注里估的，不是绝对标准；它的作用是防止明显退化，不是判"美不美"。

## 7 一句话

**精美不是风格，是约束：少墨、分层、颜色有角色、对齐、直接标注、留白。
这六条能从语料里看出来，也能被模板和 lint 执行。**
