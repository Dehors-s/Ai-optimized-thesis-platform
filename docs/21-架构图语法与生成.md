# 21 架构图：真实样本、语法与生成

> 这一版按你说的做：先去 Nature 系列和顶会论文里找**神经网络架构图 / 方法框架图**，
> 下载图注和正文引用句，逐张拆；再总结语法，最后才是工具。
>
> 样本：Nature Communications 4 张 + 顶会/预印本 10 张（Transformer、ViT、Swin、SAM、
> LOGCAN++、DCT-Mamba3D、Data Agents、神经符号、开集识别等），共 14 张；
> 下表拆解其中 12 张。存在 `corpus/figures/arch/`，元数据在 `manifest.jsonl`。

## 0 结论

架构图不是"画得漂亮"，是**把三层信息放在一张图上**：

1. **宏观**：数据从哪来、经过哪几个大块、到哪去（主链）；
2. **中观**：块与块之间怎么连（分支、残差、循环、共享）；
3. **微观**：某个块内部是什么（放大框）。

顶刊/顶会的架构图有稳定语法：**主链 ≤7 节点、一个放大框、颜色编码角色、
残差走外侧、重复用 N×、标签直接标在块上、图例 ≤2**。
我们做了 `tools/archspec.py` 把这套语法变成可渲染的 DSL（三个 demo）。

### 1.1 三个尺度，不要混

| 尺度 | 回答什么 | 例子 | 画法 |
|---|---|---|---|
| 宏观 | 整体怎么走 | SAM、Transformer、LOGCAN | 主链 + 分支，≤7 节点 |
| 中观 | 块之间怎么连 | 残差、循环、共享、多任务 | 外侧旁路、虚线回边、N× |
| 微观 | 块里是什么 | LOGCAN 的 LCA、Transformer 的 Attention | 一个放大框，虚线锚回 |

**一张图最多两个尺度。** 三个尺度全画，读者会迷路。

## 2 六条硬规则

1. **主链 ≤7 节点。** 超过就折叠进放大框，不缩字号。
2. **节点等宽等高、网格对齐。** 对齐比装饰重要；歪一个框，整张图就松。
3. **箭头正交，一个出口分叉。** 分叉从同一出口出发，不要每个分支各画一个箭头起点。
4. **残差/循环走外侧。** 旁路箭头绕开主链，不穿框。
5. **颜色编码角色，不是审美。** 数据/模块/本文/冻结/损失各一色；图例 ≤2 个算子（⊕/⊗）。
6. **标签直接标在块上。** 能写在块里/箭头上的，不进图例。

补充：

- 输入/输出可以用真实图片（SAM、ViT），中间层用块；
- 重复用 **N×** 括号，不画 N 层；
- 放大框用**虚线**，引线锚回被放大的节点；
- 图注三段：这是什么 → 怎么读（左→右/上→下）→ 边界。

## 3 工具：什么能画，什么不能

| 类型 | 工具 | 自动化 | 说明 |
|---|---|---|---|
| 块/箭头/残差 | PowerPoint、Illustrator、draw.io、Figma、TikZ | 低 | 顶会最常见；精确、可改、能嵌图片 |
| 自动布局 | Graphviz、ELK/Dagre | 中 | 适合图结构，不适合残差/循环的审美路由 |
| 模型自动生成 | Netron、PlotNeuralNet、visualkeras | 中 | 从模型文件生成，样式统一但呆板，改不动 |
| 系统循环 + 图标 | PowerPoint、Illustrator、BioRender、Flaticon | 低 | 图标是信息，不是装饰 |
| 数学复合 | matplotlib、TikZ + Illustrator | 低 | 每个数学组件单独画，再拼 |
| 文生图 | — | — | 不适合：文字会错、框对不齐、改不了、不可复现 |

**为什么文生图不行**：架构图的核心是"这个框和那个框的关系"。
生成模型给的是像素，不是关系；标签一错，图就废了。

## 4 `archspec`：把语法变成 DSL

`tools/archspec.py` 用节点/连线/分组/放大框描述架构图，输出 PNG + SVG + PDF。

```bash
py tools/archspec.py demo --out figures/arch
py tools/archspec.py render --spec figures/arch/A1.json --out figures/arch
py tools/archspec.py lint   --spec figures/arch/A1.json
```

规格核心字段：

```json
{
  "id": "A1",
  "direction": "horizontal",     // 或 vertical
  "nodes": [{"id":"enc","col":1,"row":0,"label":"Encoder","kind":"module"}],
  "edges": [{"from":"in","to":"enc"}, {"from":"in","to":"an1","route":"side","style":"--"}],
  "zoom":  {"source":"enc","title":"Encoder block","nodes":[...],"rect":[0.18,0.02,0.64,0.40]},
  "row_labels": [...],
  "separators": [0.5],
  "annotations": [{"text":"N×","x":0.05,"y":0.5}]
}
```

三个 demo：

| 图 | 结构 | 对应真实样本 |
|---|---|---|
| A1 | 两行范式对比（固定通道 vs 可变通道） | HyperFree 图 1 |
| A2 | 横向主链 + 编码器放大框 | SAM / LOGCAN++ |
| A3 | 竖排 Transformer block + 残差旁路 + N× | Transformer 图 1 |

![A2 主链 + 放大框](../figures/arch/A2.png)

lint 能查：主链是否 >7、节点标签是否过长、边是否引用不存在的节点、
zoom.source 是否存在、图注是否为空。

## 5 画一张架构图的步骤

1. **写一句话**：读者看完这张图，应该记住什么？
2. **选尺度**：范式对比 / 模型总览 / 块细节 / 系统循环。
3. **列主链**：数据 → 大块 → 输出，控制在 7 个以内。
4. **折叠细节**：选一个最需要解释的块做放大框，其余不展开。
5. **定角色色**：数据、模块、本文、冻结、损失，先定色再画。
6. **摆网格**：等宽等高，横排或竖排，残差留外侧。
7. **画箭头**：正交，一个出口分叉，残差虚线。
8. **加标注**：N×、维度、关键算子（⊕/⊗），能直接标就不做图例。
9. **写图注**：是什么 → 怎么读 → 边界。
10. **导出 PDF**，交给 Tavotto/Illustrator 拼版或微调。

## 6 我们还没做的

- 自动布局：节点多时仍需手摆坐标；ELK/Dagre 的正交路由还没接；
- 障碍避让：多条边交叉时没有自动绕行；
- 图标库：数据库/齿轮/大脑等系统图标还没有；
- 图片嵌入：输入/输出用真实图片（SAM/ViT 那样）还没支持；
- 数学面板：流形/向量场/谱这类复合面板，仍需 matplotlib/TikZ 单独画；
- 与 Tavotto 的 panel registry 打通：现在导出 PDF 后可手动拼，还没自动登记。

---

## 7 一句话

**架构图的信息量不在"画了多少块"，而在"读者能不能顺着一条链把数据流走完"。
主链是骨架，放大框是注脚，颜色是角色，残差是例外——把这四件事画对，图就成立。**
