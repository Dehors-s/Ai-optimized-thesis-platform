# 03 · 论文质量评分卡 v1.0

> 用途：① 写作前自检（选题是否立得住）② 生成后门禁（能不能进入下一阶段）③ 人工/模型评审的统一口径 ④ 平台里"分数从哪来"的解释。
> 原则：**能机器判的写成规则，不能机器判的写成行为锚点。** 所有阈值是初始值，需按学科校准。

---

## 0. 怎么用

1. 先跑 **一票否决项**（第 1 节）。命中任意一条，直接判 D，不进入打分。
2. 再按六个维度打 0–5 分，按权重折算百分制。
3. 机器可判项优先用规则（第 5 节），模型只判"行为锚点"型条目。
4. 两人独立打分，报告一致性；α < 0.5 时先校准再下结论。

```
总分 = Σ (维度得分 / 5 × 维度权重)
等级：A ≥ 85｜B 70–84｜C 55–69｜D < 55 或命中否决项
```

---

## 1. 一票否决项（任意命中即 D）

| # | 否决项 | 判定方式 |
|---|---|---|
| V1 | **伪造或无法溯源的实验数据** | 正文数字不能在 `results/` 中找到来源 |
| V2 | **引用不存在 / 与论断无关** | DOI/arXiv 不可解析，或原文不支持该句 |
| V3 | **图表与正文结论矛盾** | 图注 assertion 与正文引用句的结论方向不一致 |
| V4 | **thesis 缺失或不可证伪** | 说不出"什么结果会推翻它" |
| V5 | **结论强度超过证据强度两级以上** | 单次实验写"证明了普适规律" |
| V6 | **数据/方法描述不足以复现** | 缺数据集、缺超参、缺评价指标定义中任两项 |

> V1–V3 是"学术诚信线"，必须阻断；V4–V6 是"学术规范线"，可修复但不得发布。

## 2. 总分结构

| 维度 | 权重 | 一句话判据 |
|---|---|---|
| D1 论证 | 25 | 读者能复述出唯一主张，且每节都在推进它 |
| D2 证据 | 20 | 每个经验断言都能指到具体数据/文献，且强度匹配 |
| D3 结构 | 15 | 每段有且只有一个论证任务，删任一段都会损失论证 |
| D4 语体 | 20 | 措辞精确编码认知状态，无套话，句法有节奏 |
| D5 图表 | 15 | 一图一断言，编码正确，版式合规，图注自足 |
| D6 规范 | 5 | 引用、编号、单位、术语、格式统一 |

## 3. 分维度细则（行为锚点）

### D1 论证（25）

| 分 | 锚点 |
|---|---|
| 5 | 有唯一、可证伪、含四要素的 thesis；主张树每一层都是"必要环节"；warrant 显式且成立；限定与证据严格匹配；主动处理了最强的反驳 |
| 4 | 同上，但反驳处理较薄弱，或某条 warrant 依赖未言明的假设 |
| 3 | thesis 清楚但偏大；有主张树但存在并列（删掉一条不影响结论）；限定基本合理 |
| 2 | 只有"研究主题"没有主张；各节各自成立但不互相支撑 |
| 1 | 通篇是文献与方法的罗列，读者无法说出作者主张什么 |
| 0 | 主张自相矛盾，或主张与数据方向相反 |

**检查动作**：把 thesis 单独给一个同行看，问"你猜什么结果会推翻它"。答不出 → ≤3 分。

### D2 证据（20）

| 分 | 锚点 |
|---|---|
| 5 | 100% 数字可溯；引用全部真实且支持；每个 claim 的证据强度由规则计算并标注；不确定性（CI/n/seed）完整；关键对照公平 |
| 4 | 数字与引用可溯，但个别证据缺 CI 或 n；对照基本公平 |
| 3 | 有证据台账，但存在"证据与主张不匹配"（如用准确率证效率） |
| 2 | 部分数字无法溯源；引用存在"沾边引用" |
| 1 | 大量断言无出处；实验描述无法复现 |
| 0 | 存在编造数据（触发 V1） |

### D3 结构（15）

| 分 | 锚点 |
|---|---|
| 5 | 引言四检查点（M1-S3 / M2-S1A / M2-S1B / M3-S1）齐全；每段有 claim_step + exit_belief；move 递进而非并列；过渡由论证驱动 |
| 4 | 结构完整，个别段落的任务偏弱（如"背景补充"） |
| 3 | 有骨架，但存在 2–3 个"话题段落"（无 claim_ref） |
| 2 | 按模板填空，节内段落可任意重排 |
| 1 | 结构混乱，同一内容在多节重复 |
| 0 | 缺关键节（如无方法或无结果） |

### D4 语体（20）

| 分 | 锚点 |
|---|---|
| 5 | hedge/boost 与证据强度 100% 对齐；无黑名单套话；句长方差自然；术语全文一致；中文无"的的不休"，英文无过度名词化；信息密度高（每段至少 1 个新信息单元） |
| 4 | 对齐率 ≥ 90%；偶有套话；句法基本自然 |
| 3 | 对齐率 70–90%；每千字 3–5 处套话；句长偏均匀 |
| 2 | 明显"AI 腔"：形容词堆叠、伪递进、首句套话；对齐率 < 70% |
| 1 | 口语化或营销化；术语前后不一致 |
| 0 | 读不懂，或与学术语体无关 |

### D5 图表（15）

| 分 | 锚点 |
|---|---|
| 5 | 一图一 claim；图注首句即断言；编码与数据关系匹配；lint 全过；色盲安全；字号达标；图注含 what/how/takeaway；正文"引用结论"而非"引用编号" |
| 4 | 同上，个别图注偏描述性 |
| 3 | 图能看懂，但存在图型不当（如饼图比较）或轴截断 |
| 2 | 图是装饰；图注只写"XX 的对比"；图与正文各说各话 |
| 1 | 图不可读（字号过小、标签重叠、无单位） |
| 0 | 图误导（双轴伪造相关、面积编码半径） |

### D6 规范（5）

| 分 | 锚点 |
|---|---|
| 5 | 引用格式统一（GB/T 7714 或目标期刊）；图表编号连续、正文均有交叉引用；单位/小数位/有效数字一致；缩写首现定义；中英术语对照 |
| 4 | 个别格式瑕疵 |
| 3 | 引用格式混用；图表有编号无引用 |
| 2 | 大量格式不一致，影响阅读 |
| 1 | 无参考文献格式；图表编号混乱 |
| 0 | 抄袭/未标注来源 |

## 4. 语体规则表（中英分轨）

### 4.1 强度—措辞对齐（硬规则）

| 证据强度 | 英文允许 | 英文禁止 | 中文允许 | 中文禁止 |
|---|---|---|---|---|
| strong | demonstrate, establish, show that, consistently, robustly | may, might, possibly, appear to | 证明、表明、一致地显示 | 可能、或许、似乎、初步 |
| moderate | indicate, suggest, is consistent with, we observe, 显示 | prove, demonstrate, establish | 说明、提示、与……一致、观察到、显示 | 证明、充分表明、无疑 |
| weak | appear to, preliminary evidence, we conjecture, 初步 | 任何因果/普适断言 | 初步看来、似乎、我们推测、有待验证 | 任何因果/普适断言 |

**执行**：段落级扫描"证据句"，抽取情态词，与所引 evidence 的 `strength` 比对。不一致 → major，退回改写。

### 4.2 "AI 味"黑名单（每千字命中 ≤ 2）

**中文**：随着……的不断发展｜值得注意的是｜综上所述｜总而言之｜不仅……而且……（连用）｜本文将深入探讨｜具有重要的理论意义和实践价值｜极大地｜显著地（无统计）｜在一定程度上（滥用）｜众所周知｜毋庸置疑

**英文**：In recent years, ... has attracted increasing attention｜It is worth noting that｜In conclusion｜plays a crucial role｜significantly (无统计)｜delve into｜pave the way for｜a comprehensive understanding of｜not only ... but also ...（连用）｜In this section, we will

### 4.3 结构特征（可测量）

| 特征 | 中文建议 | 英文建议 | 测法 |
|---|---|---|---|
| 句长 | 均 25–40 字，段落内标准差 ≥ 6 | 均 18–28 词，标准差 ≥ 5 | 分句后统计 |
| 名词化 | 避免"的"字链 ≥ 3 层 | -tion/-ment/-ness 占比 ≤ 25% | 正则/词性 |
| 连接词 | 忌"首先/其次/最后"三连 | 忌每段 However/Moreover 开头 | 段落首词统计 |
| 评价形容词 | ≤ 2 个/段，且尽量量化 | 同 | 词表 |
| 信息密度 | 每段 ≥ 1 个新信息单元（数字/引文/对比/限定） | 同 | 规则 + 人判 |
| 术语一致 | 同一概念全文一种译名，首现给英文 | 同 | 术语表比对 |

### 4.4 改写示例（中文）

> 原：随着深度学习技术的不断发展，文本分类任务受到了广泛关注。值得注意的是，在低资源场景下，现有方法仍然存在诸多不足。本文提出了一种新颖的对比学习框架，不仅提高了模型的准确性，而且增强了鲁棒性。

命中：宏大开场、值得注意的是、伪递进、形容词堆叠（新颖/广泛）、无数据。

> 改：低资源文本分类的主要误差来自类内方差：在 5-way 1-shot 设定下，类内方差占总方差的 62%，而原型间距的贡献仅为 11%（表 1）。本文据此在原型网络中引入方差归一化，使 FewRel 上的 macro-F1 从 71.3 提升至 78.5（5 seed，95% CI [77.9, 79.1]），并在 10-shot 设定下保持增益（+4.2）。

改动逻辑：删套话 → 首句给断言 → 第二句给证据 → 第三句给限定（10-shot 仍有效）→ 全程有数字。字数相近，信息量差一个量级。

> 中文摘要/引言另有一套「期刊语体」规则（五段式、首先/然后/最后、禁元话语与对偶），见 [05-中文期刊语体规则](05-中文期刊语体规则.md)。本节规则管「准确」，那一份管「像不像这一行的人写的」。

## 5. 机器可判规则（可直接实现）

> 初始阈值，按学科校准。`blocker` 阻断发布，`major` 退回改写，`minor` 提示。

| Rule ID | 条件 | 级别 |
|---|---|---|
| R-ARG-01 | thesis 缺"对象/干预/效应/条件"任一 | blocker |
| R-ARG-02 | claim 无 `warrant` 字段或为空 | major |
| R-ARG-03 | `claim.strength` > 其最高证据 `strength` | blocker |
| R-ARG-04 | 存在没有任何段落引用的 claim | major |
| R-ARG-05 | 存在没有任何 claim 使用的 evidence | minor |
| R-EVD-01 | 正文数字无法在 `results/` 中定位 | blocker |
| R-EVD-02 | 引用 DOI/arXiv 不可解析 | blocker |
| R-EVD-03 | 引文 NLI 判定"不支持"（置信 > 0.8） | major |
| R-EVD-04 | 比较方向与 delta 符号不一致 | blocker |
| R-EVD-05 | 实验描述缺数据集/指标/超参任一 | major |
| R-STR-01 | 段落无 `claim_ref` | major |
| R-STR-02 | 同一节连续 3 段 `move` 相同且 `claim_ref` 相同 | minor |
| R-STR-03 | 段落字数偏离预算 > 30% | minor |
| R-STR-04 | 段落缺 `exit_belief` | major |
| R-STY-01 | strong 证据句含禁止情态词 | major |
| R-STY-02 | moderate 证据句含 demonstrate/prove/证明 | major |
| R-STY-03 | 黑名单命中（每千字 > 2） | minor |
| R-STY-04 | 段落句长标准差 < 5 | minor |
| R-STY-05 | 评价性形容词 > 3 个/段 | minor |
| R-STY-06 | 术语表外的同义混用 | major |
| R-STY-07 | weak/moderate 证据句含无统计支撑的 booster（"显著/极大地/significantly"） | major |
| R-FIG-01 | 图无 `claim_ref` | blocker |
| R-FIG-02 | 图注缺 takeaway | major |
| R-FIG-03 | 最终尺寸下字号 < 5 pt | major |
| R-FIG-04 | 条形图 y 轴不含 0 | major |
| R-FIG-05 | 双 y 轴 / 3D / 饼图用于比较 | major |
| R-FIG-06 | 标签重叠或溢出画布 | major |
| R-FIG-07 | 图注 assertion 与正文引用句结论不一致 | major |
| R-FIG-08 | 图无误差/不确定性说明（有重复实验时） | minor |
| R-NRM-01 | 引用格式与目标样式不符 | minor |
| R-NRM-02 | 图表有编号但正文无交叉引用 | minor |
| R-NRM-03 | 单位/小数位不一致 | minor |

**实现提示**：R-EVD-01/04、R-FIG-03/04/06 都可以在 200 行以内实现，收益最大，优先做。

## 7. 等级与处置

| 等级 | 含义 | 处置 |
|---|---|---|
| A ≥ 85 | 可投 | 仅做语言润色与格式检查 |
| B 70–84 | 可读但不够硬 | 针对 D1/D2 的 major 项做定向修订 |
| C 55–69 | 结构性问题 | 回到"立骨"阶段重做 claim tree |
| D < 55 或命中否决 | 不可用 | 重建，不做局部修补 |

关键判断：**C/D 级不要"润色"**。语体精修只能提升 D4，救不了 D1/D2。这是大多数 AI 写作工具最大的误区——它们只做第 4 项。

---

## 8. 标注一致性

- 至少 2 人独立打分，报告 Krippendorff's α；
- 目标 α ≥ 0.6（行为锚点足够具体时应可达）；
- 每月用 10 篇"金标准"论文校准一次；
- 模型打分与人工打分的 Spearman ≥ 0.6 才可用于门禁，否则只做提示。
