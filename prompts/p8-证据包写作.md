# p8 证据包写作（一节一次）

> 用途：在已有 `paper_ir` 与证据库之后，写某一节正文。
> 与 p3 的区别：p3 管"这段要完成什么论证任务"，p8 管"这句话的证据编号对不对"。
> 两者可以叠加：先用 p3 定任务，再用 p8 约束落笔。

---

## 输入（三样，缺一不可）

1. **本节任务**：来自 `outline.md` 的段落任务单（推进哪个主张、字数、禁止写什么）。
2. **证据包**：`project.json` 的 `evidence.allowed` 里属于本节的那些 E- 记录，JSON 数组，原样贴入。
3. **文献包**：本节引用槽位允许的 R- 记录（含 `title`、`year`、`venue`、`status`、`supports.span`）。

不要给整库，不要给全文。给多了模型会挑最顺手的，不是最该用的。

---

## 规则

### 证据

- 每个**断言句**必须以 `[E-0001]` 结尾；一句多条证据写 `[E-0001][E-0007]`。
- 只能用证据包里出现的编号。**不许发明编号，不许改数值。**
- 证据的 `status` 是 `disputed` → 不要用，输出 `CONFLICT`。
- `status` 是 `user_asserted` → 可以写，但句子要带限定（"据作者提供的数据"），不许写成测量结论。
- `strength=weak` 的证据只能支持弱表述：不许出现"显著""证明""充分说明"。
- 负证据（`type=negative`）必须用在该用的地方（失效条件、局限），不许藏起来。

### 文献

- 只能引用文献包里列出的 R- 记录，按文献库顺序编号。
- 每处引用要能回答"它支持哪一句"；支持不了就不要引。
- 需要新的引用而包里没有 → 输出 `NEED_REF: {检索式}`，不要自己编。

### 不许做的事

- 不许新增数字、百分比、倍数、年份。
- 不许新增主张。想加就输出 `IR_PATCH_SUGGESTION: {...}`。
- 不许用"显著提升""全面优于""证明了"这类词（除非证据是 strong 且有统计检验）。
- 不许为凑字数写没有证据编号的过渡段。

---

## 输出格式

```markdown
### <小节标题>

<正文，断言句带 [E-xxxx]，引用带 [n]>

<!--
EVIDENCE_USED: E-0007, E-0008
REFS_USED: 12, 15
GAPS: 缺少后处理在重叠划分上的对照
-->
```

若证据不足，整节不要硬写，输出：

```markdown
INSUFFICIENT_EVIDENCE
需要：<缺什么>
建议：<补哪次实验/哪张表/哪篇文献>
```

---

## 交稿前自检（逐条打勾）

- [ ] 每个断言句都有 `[E-]` 编号，且编号都在证据包里
- [ ] 没有出现证据包之外的数字
- [ ] `disputed` 证据一条没用
- [ ] `weak` 证据没有配强表述
- [ ] 每条引用都能指出它支持哪一句
- [ ] 没有新增主张（有就写进 `IR_PATCH_SUGGESTION`）
- [ ] 证据不足时输出了 `INSUFFICIENT_EVIDENCE`，而不是圆场

---

## 为什么要有这一层

模型看不见"证据够不够"，只看得见"句子顺不顺"。给它一个封闭的证据包，
再要求它逐句标注，等于把"这段话有没有依据"从主观判断变成可核对的事实。
检查器只看编号，不看文采——文采由 p4 管，依据由这一层管。
