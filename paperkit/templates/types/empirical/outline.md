# 章节骨架（实证论文模板）

> 角色序列：abstract → intro → related → problem → method → results → discussion → conclusion。
> 贡献分解由 `paper_ir.json` 的 `decomposition` 决定，方法章按分解项展开。

## 1 引言

| 段 | 修辞任务 | 必须回答 |
|---|---|---|
| 1.1 | 任务与重要性 | 这个问题为什么值得做 |
| 1.2 | 现有方法的缺口 | 它们假设了什么、漏了什么 |
| 1.3 | 本文主张 | thesis 一句话、贡献三条以内 |
| 1.4 | 边界 | 本文不做什么 |
